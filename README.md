# Pet Care Platform — India Landing Page

A polished, static landing page created from the uploaded August 2026 market-research presentation.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive visual design
- `script.js` — service-module interaction, mobile navigation, scroll reveal

## Run
Open `index.html` directly in a browser. No build step is required.

## Notes
- The page intentionally presents the product as being in the **market research phase**, not as a launched service.
- The six platform modules and phased roadmap are based on the presentation.
- The market statistics include the source attribution used in the presentation.
- The research CTAs use the email address shown in the presentation.
- There is no backend; research CTAs open the user's email client.
